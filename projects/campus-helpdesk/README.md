# Campus helpdesk

Build a small service that receives student requests, identifies what they need, prepares a useful next step and routes sensitive cases to a person.

## Start

1. Read the [project brief](brief.md).
2. Inspect the [sample tickets](sample-tickets.csv).
3. Choose one request category for the first working flow.
4. Use the workshop modules to frame, build and test it.
5. Run the [test scenarios](test-scenarios.md).

## The first version should

- accept a request in ordinary language;
- identify the likely category and missing information;
- offer a useful response or next action;
- send sensitive or uncertain cases to a person;
- preserve enough context for that person to continue.

It does not need accounts, live college systems or a polished interface.
