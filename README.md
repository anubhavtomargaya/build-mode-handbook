# Build Mode handbook

The public material behind Build Mode workshops. Use it to run a session, follow one independently or adapt the exercises to another field.

## Start here

- [Run the software-with-AI workshop](workshops/software-with-ai/README.md)
- [Browse the modules](modules/README.md)
- [Build the campus helpdesk project](projects/campus-helpdesk/README.md)

A **module** teaches one part of the method. A **project** gives the method something real to work on. A **workshop** combines selected modules and a project into a timed session.

The first workshop uses modern software as its setting. The method is intended to expand into other fields.
