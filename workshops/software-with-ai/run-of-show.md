# Run of show

Baseline: 3 hours 30 minutes, including one break.

| Time | Work |
| --- | --- |
| 15 min | Introduce the project and form groups |
| 20 min | Map the real work |
| 25 min | Frame the problem |
| 30 min | Prepare context and work with AI |
| 50 min | Build the first working flow |
| 10 min | Break |
| 25 min | Test ordinary and difficult cases |
| 20 min | Review users, value and scale |
| 15 min | Explain decisions and close |

Keep the first build small. If time slips, reduce features rather than removing testing or the final explanation.
